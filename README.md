# Little Learners Studio – Book Shop

A one-page shop for Dr. Samrin Sarwar's printable kids' books.

- **Buy buttons** open WhatsApp with the order message ready. A Razorpay/UPI payment link is sent back, then the PDF is delivered on WhatsApp.
- **Free app** section links to the Little Learners English app: https://littlelearners.pages.dev
- Static site (index.html + img/). Host on GitHub Pages: Settings → Pages → Deploy from a branch → `main` / root.
